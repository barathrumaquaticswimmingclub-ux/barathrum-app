Fase bulanan dari file Coach

Jendela speed test

Ringan saat mencatat, jelas saat menilai.

Program terlaksana: pilih Semua selesai, Sebagian, atau Tidak latihan. Untuk Sebagian, ubah teks agar sesuai dengan set yang benar-benar dijalankan.

Waktu: pada set dengan @, ontime berarti mampu mengikuti send-off. Pada sesi teknik, artinya sesuai alokasi waktu. Pilih Belum dinilai jika belum mengukur; aplikasi tidak akan mengarang hasil.

Keterangan: boleh kosong. Tulis pengecualian, misalnya “Bastian pulang lebih awal” atau “teknik mulai turun pada dua repetisi terakhir”.

Laporan line menilai kelompok. Catatan ini tidak otomatis menjadi absensi BRTM atau transaksi SPP.

Data & cadangan

Program, susunan line, laporan, target peak, dan respons AI tersimpan di PostgreSQL BRTM. Riwayat revisi dipertahankan. Ekspor latihan juga masuk dalam cadangan operasional Owner.

Edit di situs versi awal dapat dipindahkan dengan Unduh cadangan edit, lalu diimpor di sini. Tanggal yang sudah memiliki draf server akan dilewati.
