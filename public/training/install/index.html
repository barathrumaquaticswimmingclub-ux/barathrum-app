Program Latihan

Program, laporan, dan evaluasi latihan dalam satu ruang kerja.

Buka aplikasi

Android: buka tautan ini di Chrome. Jika dibuka dari ChatGPT, pilih menu ⋮ → Buka di Chrome.

iPhone: buka di Safari → Bagikan → Tambah ke Layar Utama.

Pasang di layar utama

Android: buka halaman ini di Chrome → menu ⋮ → Tambahkan ke layar utama → Instal.

iPhone: buka halaman ini di Safari → Bagikan → Tambah ke Layar Utama.

Jika pilihan Instal belum tersedia, muat ulang halaman lalu coba lagi. Aplikasi memerlukan internet untuk data latihan.
